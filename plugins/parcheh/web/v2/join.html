Need to install parcheh?

In Codex, open the plugin marketplace. Add the repository below, then find and install parcheh.

  1. In the Claude desktop app, open a local Code chat. Open + → Add plugins or Plugins → Browse plugins.
  2. Add a marketplace from the repository below. If needed, open Customize → Plugins → Add → Add marketplace.
  3. Install parcheh for your user account. In Marketplaces, select parcheh-pilot to enable automatic updates.
