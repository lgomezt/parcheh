First time on this Mac? Install parcheh

  1. In the Claude desktop app, open a local Code chat. Open + → Add plugins or Plugins → Browse plugins.
  2. Add a marketplace from a repository. If you don’t see that option, open Customize → Plugins → Add → Add marketplace. Paste this address.
  3. Install parcheh for your user account. In Marketplaces, select parcheh-pilot and enable automatic updates to receive new versions.
